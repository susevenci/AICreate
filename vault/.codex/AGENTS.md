# AGENTS.md — 执行契约

> 本文件面向执行型 Agent（Codex / Claude Code / Qoder 等）。任何 Agent 在本 vault 内执行任务前必须先读本文件，并遵守全部约束。
> 契约优先级：`00-工作台/_schema.md`（字段）＞ 本文件（行为）＞ 各 `SKILL.md`（任务）＞ 用户当次口头指令中的格式偏好。

## 1. 目录职责

| 目录 | 职责 | Agent 是否可写 |
|------|------|----------------|
| `00-工作台/` | 视图层与配置。页面笔记只放查询，不放业务数据 | 否（仅允许人工改） |
| `01-收件箱/` | 未分类素材、随手记录、AI 暂存产物 | 是（唯一默认入口） |
| `01-收件箱/_ai-output/` | Agent 输出暂存区，等待人工确认 | 是 |
| `02-知识库/` | 长期笔记 | 是（追加，不改他人笔记） |
| `03-对标/` | 博主与作品快照 | 是 |
| `04-选题/` | 选题卡 | 是（新建；改状态需人工确认） |
| `05-拆解/` | 拆解记录 | 是 |
| `06-资产/` | 四类可复用资产 | 是（新建需人工确认） |
| `07-稿件/` | 稿件与版本 | 是（仅追加内容到指定小节） |
| `08-作品/` | 已发布作品与指标 | 是（新建/补指标） |
| `09-计划/` | 任务与复盘 | 是（仅 `source: ai` 的草稿） |
| `10-收支/` | 流水 | 是（新建） |
| `11-画板/` | Excalidraw | 否 |
| `.codex/` | 用户自定义 Skill（覆盖同名内置）与运行记录 | 否（由人工维护） |
| `.trash/` | 软删除 | 是（只写不读） |

**Skill 来源分两级**：`app/skills/` 是内置只读，随产品发布，保证空库也能完成初始化；`vault/.codex/skills/` 是用户自定义，同 id 时用户目录优先。内置目录禁止修改，需要定制请复制一份到 vault 后再改。

## 2. 写入规则

0. **唯一写入口**：Web 层的所有业务写入都经 `POST /api/skills/:id/run`；动作型 Skill 内部才落盘。Agent 直接写文件时同样遵守后续条款。
1. **先读后写**：写入任何已有笔记前必须完整读取，禁止凭记忆覆盖。
2. **只追加不重写**：对 `07-稿件/` 的正文，只允许在指定小节内追加或替换该小节内容，不得重排其他小节。
3. **禁删**：不执行删除、不执行移动用户文件；需要删除时移到 `.trash/` 并保留原路径记录。
4. **禁改视图**：不得修改 `00-工作台/` 下任何文件。
5. **禁编造数据**：没有来源的数字必须留空或写 `待补充`，不得估算后写成事实。
6. **一文件一对象**：不得把多条选题 / 多条流水合并进一个文件。
7. **命名按规范**：遵循 `_schema.md` 第 2 节命名规则，重名加 `-2`。

## 3. 输出落盘流程

```
1. 生成结果 → 写入 01-收件箱/_ai-output/{YYYYMMDD-HHmm}-{skill}-{slug}.md
2. 该文件必须包含：frontmatter（type + 目标实体字段）+ 正文 + 末尾「## 运行信息」小节
3. 「## 运行信息」固定四行：
   - skill: {skill 目录名}
   - version: {SKILL.md 中的版本}
   - runAt: {ISO 时间}
   - inputRefs: {本次读取的笔记 wikilink 列表}
4. 在回复中输出一行「待确认：{文件路径}」，等待人工移动到正式目录
5. 人工确认后，才允许写入 04/06/07/08 等正式目录
```

## 4. 字段规范

- 一律以 `00-工作台/_schema.md` 为准，禁止自造字段。
- 枚举值必须用小写英文（`selected` 而非 `已选定`）。
- 关联一律 `"[[文件名词]]"`。
- 日期 `YYYY-MM-DD`。

## 5. 任务执行通用步骤

1. 读取任务上下文：目标笔记 + 其 `refs`/`topic`/`assets` 指向的一层笔记（不超过 6 篇）。
2. 读取对应 `SKILL.md`，按其「执行步骤」逐条执行。
3. 按 `template.md` 组织输出骨架，字段必须齐全。
4. 自检：枚举合法、必填非空、链接存在、无编造数据。
5. 写入暂存区并输出「待确认」。

## 6. 上下文预算

| 项 | 上限 |
|----|------|
| 单次输入笔记数 | 6 篇 |
| 单次输入字数 | 12000 字 |
| 单次输出字数 | 4000 字 |

超出时按相关度截断，并在「## 运行信息」注明 `truncated: true`。

## 7. 禁止动作清单

- 修改 `00-工作台/`、`.codex/`、`12-模板/`
- 物理删除文件
- 跨目录批量移动
- 修改 `_配置.md` 的 `name`（该字段只能由人工或 Web 设置页修改）
- 把汇总数字写死在作品笔记里（汇总一律由视图现算）
- 在正文中写入密钥、账号、Cookie、手机号等敏感信息

## 8. 失败处理

- 字段校验失败：不写盘，返回缺失字段名。
- 上下文读取失败：降级为仅用用户提供的内容，并在输出中标注 `degraded: true`。
- 目标文件已存在：不覆盖，改名追加 `-2`，并在输出中说明。
