# 发布与经营

**导航**　[[首页]] ｜ [[选题池]] ｜ [[拆解与沉淀]] ｜ [[创作]] ｜ [[发布与经营]] ｜ [[收支]]

> 同一内容跨平台只记一条作品；播放、咨询、成交三口径互不推算。
> 成交按记录数统计，不去重。本页只做查询。

## 本月总览

```dataviewjs
try {
  const ym = dv.date("today").toFormat("yyyy-MM");
  const works = dv.pages('"08-作品/作品"').where(p => p.type === "work");
  const metrics = dv.pages('"08-作品/指标"').where(p => p.type === "metric");
  const cur = metrics.where(p => p.date && p.date.toFormat("yyyy-MM") === ym);
  const sum = (key) => cur.reduce((s, m) => s + (Number(m[key]) || 0), 0);
  dv.table(
    ["指标", "数值", "口径"],
    [
      ["本月发布", works.where(p => p.publishDate && p.publishDate.toFormat("yyyy-MM") === ym).length + " 篇", "按 publishDate"],
      ["本月成交", sum("deals") + " 笔", "按记录数，不去重"],
      ["本月播放", String(sum("views")), "不用于推算成交"],
      ["缺少日期", metrics.where(p => !p.date).length + " 条", "不计入月度统计"],
    ]
  );
} catch (e) {
  dv.paragraph("发布经营统计渲染失败：" + e.message);
}
```

## 作品

```dataview
TABLE publishDate AS "发布日期", platforms AS "平台", draft AS "原稿"
FROM "08-作品/作品"
WHERE type = "work"
SORT publishDate DESC
LIMIT 100
```
