# 拆解与沉淀

**导航**　[[首页]] ｜ [[选题池]] ｜ [[拆解与沉淀]] ｜ [[创作]] ｜ [[收支]]

> 三步：放入素材 → 核对原文 → 拆解结果。结论里的做法再另行沉淀为资产。
> 本页只做查询，不存放业务数据。

## 三步进度

```dataviewjs
try {
  const items = dv.pages('"05-拆解"').where(p => p.type === "analysis");
  const stages = [["intake", "1 放入素材"], ["verify", "2 核对原文"], ["result", "3 拆解结果"]];
  for (const [key, label] of stages) {
    const list = items.where(p => p.stage === key).sort(p => p.file.mtime, "desc");
    dv.header(3, label + "（" + list.length + "）");
    if (list.length === 0) { dv.paragraph("—"); continue; }
    dv.list(list.map(p => p.file.link));
  }
} catch (e) {
  dv.paragraph("拆解进度渲染失败：" + e.message);
}
```

## 资产四库

```dataviewjs
try {
  const assets = dv.pages('"06-资产"').where(p => p.type === "asset");
  const types = [["angle", "选题角度"], ["structure", "文案结构"], ["opening", "开场白"], ["title", "标题"]];
  dv.table(
    ["资产库", "条数", "最近更新"],
    types.map(([key, label]) => {
      const list = assets.where(p => p.assetType === key).sort(p => p.file.mtime, "desc");
      return [label, list.length + " 条", list.length ? list[0].file.link : "—"];
    })
  );
} catch (e) {
  dv.paragraph("资产统计渲染失败：" + e.message);
}
```
