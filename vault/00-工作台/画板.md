# 画板

**导航**　[[首页]] ｜ [[创作]] ｜ [[画板]] ｜ [[资产库]]

> Web 端只做索引与新建；绘制在 Obsidian 的 Excalidraw 中完成。

## 历史画板

```dataview
TABLE title AS "名称", linkedDraft AS "关联稿件", file.mtime AS "最后修改"
FROM "11-画板"
WHERE type = "board"
SORT file.mtime DESC
LIMIT 100
```

## 说明

- 新建画板会生成一篇 `type: board` 的笔记，在 Obsidian 中用 Excalidraw 打开即可绘制。
- 录制卡片从创作页发起，完成后同样落到 `11-画板/`。
