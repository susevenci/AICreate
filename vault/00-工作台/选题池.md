# 选题池

**导航**　[[首页]] ｜ [[选题池]] ｜ [[创作]] ｜ [[收支]]

> 数据来自 `04-选题/`，一条选题一篇笔记。状态流转：候补 → 研究中 → 已选定 → 创作中 → 已归档。
> 「问题」与「材料」为空时不得置为已选定。

## 状态总览

```dataviewjs
try {
  const pages = dv.pages('"04-选题"').where(p => p.type === "topic");
  const cols = [
    ["backlog", "候补"],
    ["researching", "研究中"],
    ["selected", "已选定"],
    ["in-production", "创作中"],
    ["archived", "已归档"],
  ];
  const summary = cols.map(([k, label]) => label + " " + pages.where(p => p.status === k).length).join(" · ");
  dv.paragraph("共 " + pages.length + " 条　｜　" + summary);
  for (const [key, label] of cols) {
    const items = pages.where(p => p.status === key).sort(p => p.file.mtime, "desc");
    dv.header(3, label + "（" + items.length + "）");
    if (items.length === 0) {
      dv.paragraph("—");
      continue;
    }
    dv.list(items.map(p => {
      const fit = p.fit ? " ｜适配 " + p.fit : "";
      const angle = p.angle ? " ｜" + p.angle : "";
      return p.file.link + fit + angle;
    }));
  }
} catch (e) {
  dv.paragraph("选题看板渲染失败：" + e.message);
}
```

## 明细

```dataview
TABLE status AS "状态", origin AS "来源", problem AS "问题", material AS "材料", fit AS "适配", file.mtime AS "更新"
FROM "04-选题"
WHERE type = "topic"
SORT file.mtime DESC
LIMIT 100
```
