# 收支

**导航**　[[首页]] ｜ [[选题池]] ｜ [[创作]] ｜ [[收支]]

> 金额与成交笔数分开记录：`amount` 是钱，作品的 `deals` 是笔数，两者不互相推算。
> 缺少日期的流水不计入月度统计，会在下方显式提示。

## 本月汇总

```dataviewjs
try {
  const all = dv.pages('"10-收支"').where(p => p.type === "ledger");
  const ym = dv.date("today").toFormat("yyyy-MM");
  const cur = all.where(p => p.date && p.date.toFormat("yyyy-MM") === ym);
  const sum = (kind) => cur.where(p => p.kind === kind).reduce((s, p) => s + (Number(p.amount) || 0), 0);
  const income = sum("income");
  const expense = sum("expense");
  dv.table(
    ["指标", "数值", "口径"],
    [
      ["本月收入", "¥" + income.toFixed(2), "按流水金额合计，非笔数"],
      ["本月支出", "¥" + expense.toFixed(2), "按流水金额合计"],
      ["本月净额", "¥" + (income - expense).toFixed(2), "收入 - 支出"],
      ["本月记录", cur.length + " 条", "按笔记条数"],
    ]
  );
  const byCat = {};
  for (const p of cur) {
    const key = (p.kind === "income" ? "收：" : "支：") + (p.category ?? "未分类");
    byCat[key] = (byCat[key] || 0) + (Number(p.amount) || 0);
  }
  const rows = Object.entries(byCat).sort((a, b) => b[1] - a[1]).map(([k, v]) => [k, "¥" + v.toFixed(2)]);
  if (rows.length > 0) dv.table(["分类", "金额"], rows);
  const missing = all.where(p => !p.date).length;
  if (missing > 0) dv.paragraph(`> 数据质量：${missing} 条流水缺少日期，未计入月度统计。`);
} catch (e) {
  dv.paragraph("收支统计渲染失败：" + e.message);
}
```

## 明细

```dataview
TABLE kind AS "类型", amount AS "金额", date AS "日期", category AS "分类", work AS "关联作品", note AS "备注"
FROM "10-收支"
WHERE type = "ledger"
SORT date DESC
LIMIT 100
```
