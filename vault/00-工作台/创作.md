# 创作

**导航**　[[首页]] ｜ [[选题池]] ｜ [[创作]] ｜ [[收支]]

> 围绕当前稿件推进六步：聊思路 → 写文案 → 起标题 → 做封面 → 发布检查 → 发布。
> 切换步骤只改 `step` 字段，正文不重排。`audience` 为空时不允许进入文案之后。

## 流水线

```dataviewjs
try {
  const drafts = dv.pages('"07-稿件"')
    .where(p => p.type === "draft" && p.status === "active")
    .sort(p => p.file.mtime, "desc");
  const steps = [
    ["idea", "聊思路"],
    ["copy", "写文案"],
    ["title", "起标题"],
    ["cover", "做封面"],
    ["checklist", "发布检查"],
    ["publish", "发布"],
  ];
  if (drafts.length === 0) {
    dv.paragraph("暂无进行中的稿件。从选题池选定一个方向后新建稿件。");
  }
  for (const d of drafts) {
    const idx = steps.findIndex(s => s[0] === d.step);
    const bar = steps.map((s, i) => (i === idx ? "**【" + s[1] + "】**" : s[1])).join(" → ");
    dv.paragraph(d.file.link + "　" + bar);
    if (!d.audience) {
      dv.paragraph("　　> 缺少「这篇解决谁的什么问题」，补齐后才能进入文案阶段。");
    }
    if (d.topic) dv.paragraph("　　来源选题：" + d.topic);
  }
} catch (e) {
  dv.paragraph("创作视图渲染失败：" + e.message);
}
```

## 稿件明细

```dataview
TABLE step AS "步骤", audience AS "目标读者", topic AS "来源选题", version AS "版本", file.mtime AS "最后编辑"
FROM "07-稿件"
WHERE type = "draft"
SORT file.mtime DESC
LIMIT 100
```

```dataview
TABLE length(assets) AS "引用资产数", file.mtime AS "更新"
FROM "07-稿件"
WHERE type = "draft" AND length(assets) > 0
SORT file.mtime DESC
```
